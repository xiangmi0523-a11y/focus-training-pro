# 晓米脑力

根据视频《7个脑训练》做的 iOS 脑力训练 App，黑金风格，原生 SwiftUI。

## 七个训练

| # | 训练 | 玩法 |
|---|---|---|
| 1 | 舒尔特方格 | 经典 · 倒数 · 字母 · 诗句 · 流动 · 红金交替 |
| 2 | 斯特鲁普训练 | 说颜色 · 数个数 · 规则切换 · 辨方位（可语音作答） |
| 3 | 记忆清单 | 顺序回忆 · 倒序回忆 · 定位提问 · 找变化 |
| 4 | 听数字 | 顺背 · 倒背 · 鸡尾酒会 · 排序背 |
| 5 | 镜像画 | 镜像对称 · 复合节奏 · 同向平移 · 左右异形 |
| 6 | 快速分类 | 按类别 · 规则切换 · 隐藏规则 |
| 7 | 串成故事 | 串成故事 · 接龙提问 · 数字编码 · 延迟回忆 |

每个玩法 30 级自适应难度：做得好升级、做不好降级；熟练度越高解锁越多玩法。
另有每日三项训练、连续打卡日历、七维脑力雷达图和成绩曲线。数据只存在手机本地。

## 构建

推送到 `main` 后 GitHub Actions 自动：

1. 跑核心逻辑单元测试（`BrainCore`）
2. 生成思源宋体子集、用 XcodeGen 生成工程
3. 编译模拟器版并截图
4. 编译未签名 IPA（用全能签签名安装）

提交信息带 `[release]` 时发布到 Releases。

## 目录

- `BrainCore/` 纯逻辑：出题、评分、自适应难度、存档（可单独 `swift test`）
- `App/` SwiftUI 界面、7 个训练、声音与语音识别
- `project.yml` XcodeGen 工程描述
